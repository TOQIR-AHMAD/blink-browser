! Title: Privacy Browser - built-in tracker list
! Version: 1
! Expires: never (this list ships with the browser and is not fetched)
! License: same as this project
!
! This is a small, hand-written starter list of well-known analytics and
! tracking endpoints, written for this project so that the browser blocks
! something useful out of the box without redistributing a third-party list
! under its own licence, and without fetching anything from a
! developer-controlled server (PLAN.md 20, 21).
!
! It is deliberately conservative: only hosts whose entire purpose is
! measurement, and only as third-party requests, so first-party analytics on a
! site you are actually visiting is not caught by accident.
!
! For real coverage, add a maintained list (EasyPrivacy, EasyList) in
! Settings > Privacy > Filter lists. The browser will tell you where it came
! from and what fetching an update reveals to that list's host.
